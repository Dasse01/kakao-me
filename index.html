카카오톡 나에게 보내기

입력한 문구를 내 카카오톡 "나와의 채팅"으로 보냅니다.

로그인 필요
처음 설정 방법
  1. 카카오 개발자 콘솔 > 플랫폼 > Web에 이 사이트 주소(https://○○.vercel.app)를 등록
  2. 카카오 로그인 활성화, Redirect URI에 같은 주소를 등록 (끝에 / 없이 주소만, 이 페이지가 열리는 주소와 동일해야 함)
  3. 동의항목에서 "카카오톡 메시지 전송(talk_message)" 설정
  4. 보안 > Client Secret은 사용하지 않음(비활성)으로 두기
  5. 위 칸에 JavaScript 키를 넣고 저장 후 로그인
